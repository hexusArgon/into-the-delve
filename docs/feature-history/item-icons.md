# Иконки вещей

У каждой вещи снаряжения иконка `assets/items/<id>.webp`; имя файла — id вещи, регистр важен
(`rare-maxHp-poisonRes`). Исходники — `art/items/<id>.jpg`, 1024² на пурпурном фоне.

## Нарисованные скриптом (13.11.2026)

38 иконок были рисунками. Остальные 67 нарисовал `scripts/draw-item-icons.py`: генерация картинок iDos
в тот момент была недоступна (кредиты периода кончились), а сеть сборки не достаёт CDN iDos.

- Простые и необычные вещи — векторные фигуры в духе рисунков: тёмный контур, приглушённые цвета,
  свет слева сверху, тень справа снизу. Свечения только внутри контура: снаружи они ложатся на
  пурпур и после вырезания фона дают розовую кайму.
- Редкие и эпические вещи названы по материалам (Sinew Wax = Sinew + Wax). Их иконка — железный
  оберег, внутри иконки материалов, камень внизу цвета редкости: синий — редкая, фиолетовый —
  эпическая. Слово → материал — таблица `MATERIAL` в скрипте.

Скрипт не трогает уже существующие исходники. Чтобы заменить иконку рисунком, положите
`art/items/<id>.jpg` и запустите `npm run assets`. Чтобы перерисовать векторную, удалите её исходник и
запустите скрипт, затем `npm run assets`.

Загрузчик (`game/sprites.ts`) берёт id из имени файла с заглавными буквами: раньше шаблон пропускал
их молча, и у редких вещей иконки не было бы даже при наличии файла.
