# Обучение: все оружия и стартовый выбор

Промпт для кодера. Обучение уже есть (`game/tutorial.ts`, `game/controller.ts`, `game/hub.ts`). Его не переписывать. Добавить пробу всех девяти типов и выбор одного в конце. Этот выбор заменяет меч как единственное оружие нового забега.

Числа оружия, щит, стан, Blink и скелета не менять. Новых типов не вводить. Тексты урока писать по-английски, как соседние строки `LESSON_COPY`.

## Что уже есть

Шаги: хаб → `move` → `turn` → `attack` (меч) → `blink` → `wait` → `finish` → `done`.

Комната `cp1_20_12X12_9001`. Оружие в уроке всегда меч: `tutorialRun` и `RoomController` подставляют `"sword"`. Экипировка пустая. Монстр id `"7"`, скелет-страж, только укус (`cooldowns.swing = 99` не снимать). Двери никуда не ведут.

`freshLoadout()` кладёт в руки меч. Хаб собирает кит `{ weapon: "sword", owned: ["sword"] }`. Другого сохранения оружия нет: после обновления страницы мешок собирается заново.

Промах всё равно тратит ход, и `attack` возвращает `true`. Зачёт удара в уроке уже такой: важен вызов, не попадание. Так и оставить. Один взмах парных клинков — один вызов, не два клика.

## Что сделать

После поворота игрок бьёт каждым типом по одному разу, в порядке `WEAPONS`. Меч — это нынешний шаг `attack`, отдельный шаг меча не добавлять. Дальше топор, парные, копьё, посох, перчатки, пистолет, один раз R, винтовка, дробовик. Затем как сейчас: Blink, ждать, добить скелета, если он жив. Последний шаг — выбор одного оружия. Клик по нему закрывает урок и открывает хаб.

Скелет может умереть раньше последнего оружия: у него обычные HP, урон оружия не уменьшать и не лечить его. Оставшиеся типы всё равно проходятся одним взмахом в пустую. Если к шагу «добить» комната уже выиграна, этот шаг сам переходит к выбору. Второго монстра не спавнить.

Смена типа между шагами — не ход и не действие игрока. Код пишет `state.weapon`, `run.weapon` и полный магазин (`ammo = magazine`, у ближнего боя `null`), затем `refresh`. Фигура на полу берётся из уже существующего `attackCells`. Инвентарь на эти девять типов не пополнять.

На шаге R зачёт — `reload` вернул `true`. К этому моменту пистолет уже сделал один выстрел, магазин не полный. Полный магазин шаг не закрывает.

## Выбор и старт игры

Ключ `localStorage`: `dungeon-weapon`. Значение — `WeaponId`.

- Ключа нет — стартовое оружие меч, как сейчас.
- «Пропустить» ключ не пишет. Урок помечается пройденным, в руках остаётся меч.
- Клик по типу на последнем шаге пишет ключ и только тогда ставит `dungeon-tutorial` = `"1"`.

`freshLoadout(id = "sword")` создаёт один экземпляр этого id и надевает его. Аргумент по умолчанию `"sword"`, чтобы текущие тесты мешка не менять. Хаб читает ключ и передаёт id в `freshLoadout`. Кит: `weapon` и `owned` — этот один id, не все девять.

Смерть в уроке по-прежнему поднимает «Забег оборвался» и заново открывает тот же шаг. Комната при этом собирается с оружием этого шага, не с мечом. На шагах Blink, ждать и добить оружие — дробовик, последний опробованный. Выбор при смерти не записывается.

## Шаги

Зачёт только своим действием. Пока шаг не закрыт, остальные боевые действия не вызывать.

1. Хаб. Без изменений.
2. `move`, `turn`. Без изменений.
3. Девять ударов по порядку `WEAPONS`. Текст плашки — `weapon.name` и `weapon.figure`, плюс одна строка: «Left-click. A miss still spends the turn.» Зачёт: `attack` вернул `true`.
4. `reload`, сразу после пистолета. «R reloads. The pistol is not full, so this spends the turn. A later empty pistol also reloads on left-click. The rifle and shotgun do not.» Зачёт: `reload` вернул `true`.
5. `blink`, `wait`. Без изменений.
6. `finish`. Текст про укус скелета оставить. Если исход уже `won` на входе в шаг — сразу `pick`.
7. `pick`. Девять кнопок в порядке `WEAPONS`, подпись `weapon.name`. Спрайты — те же холсты, что инвентарь хаба уже рисует через `paintWeaponIcon`. Новые картинки не делать. Текст: «Pick the weapon you start with. The doors open when the enemy is dead. Tab opens the floor map. This lesson is one room.» Клик записывает id, ставит флаг урока и открывает хаб. Отдельная кнопка «To the hub» на этом шаге не нужна.

«Пропустить» на каждом шаге, включая выбор. Настой, порох, инвентарь, аукцион, гильдию, экипировку и способности в урок не добавлять.
