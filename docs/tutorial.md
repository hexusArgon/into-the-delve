# Обучение управлению

Гайд для агента, который добавляет первое обучение. Учить только тому, что уже есть в коде. Новых правил боя, чисел и систем не вводить.

Игрок видит обучение один раз: первый заход в игру, до обычного хаба. Повторно само не запускается.

## Уже есть, это и учить

Хаб (`game/hub.ts`): клик по силуэту, не по прямоугольнику.

| Силуэт | Куда |
| --- | --- |
| В приключение | `showRoom` → этаж |
| Инвентарь | оружие, экипировка, четыре пустых слота |
| Аукцион | локальные лоты |
| Гильдия | экран гильдии |
| Шестерёнка | музыка и звуки, память в `localStorage` |

Бой (`game/controller.ts`):

| Ввод | Что делает |
| --- | --- |
| WASD или стрелки, зажать | шаг. Повтор каждые 0,2 с, когда предыдущий шаг дорисован |
| Shift+WASD или Shift+стрелки | поворот. Ход не тратится |
| ЛКМ | поворот к клетке курсора и удар. Фигура оружия уже нарисована на полу |
| ПКМ | выбор Blink. Ещё раз ПКМ — отмена, заряд не тратится |
| Esc | меню забега: вернуться в игру, настройки, сдаться |
| ЛКМ по подсвеченной клетке Blink | телепорт. Ромб: сумма шагов по осям не больше 3. Клетка 2 и 2 не входит |
| R | перезарядка. Меч ход не тратит: «Это оружие не перезаряжается.» |
| X | ждать. Ход тратится, мир ходит |
| Tab | карта этажа. Повтор закрывает |

После действия игрока ходят живые монстры, потом тики. Пока рисуется шаг, ввод закрыт. Пустой пистолет по ЛКМ сам перезаряжается. Винтовка и дробовик — нет.

Кнопки внизу комнаты: Новый этаж, Заново, В хаб. В первое обучение их не вставлять.

Стартовая комната обычного этажа без монстра. Для урока удара она не годится.

## Чего в уроке нет

Не учить инвентарь, аукцион, гильдию, экипировку, пустые слоты способностей, стихии, меню Esc, новый этаж и заново. Не подменять урон, щит, Blink и монстра. Не рисовать обычную атаку врага заранее: её предпросмотра в игре нет.

## Память

Ключ `localStorage`: `dungeon-tutorial`.

- нет ключа — урок;
- `"1"` — урок пройден или пропущен.

Ставить `"1"` на последнем шаге и на «Пропустить». «Заново» и смерть ключ не ставят. Смерть поднимает уже существующую плашку «Забег оборвался»; кнопка «В хаб» с урока возвращает на тот же шаг комнаты, не в обычный этаж.

Кнопку «Пропустить» показать на каждом шаге. Она закрывает урок и открывает обычный хаб.

## Комната урока

Не вызывать `createRun`. Одна комната, уже лежащая в `data/rooms.ts`: `cp1_20_12X12_9001` («Колонный зал», 12×12).

- оружие — меч, даже если в хабе надет другой тип;
- экипировка — пустая (`EMPTY_GEAR`);
- монстр — id `"7"`, скелет-страж: только укус, без рывка и снаряда;
- точки героя и монстра — из паттерна, не сдвигать;
- двери этой комнаты никуда не ведут. После победы не делать переход в случайный этаж.

Текст урока — отдельная плашка. Не писать его в `state.note`: бой его затирает. Плашка не закрывает героя и монстра.

Пока шаг не выполнен, остальные боевые действия не вызывать. Поворот и шаг на шаге «иди» не открывают удар. Мир при этом живой: скелет на ход игрока отвечает по обычным правилам.

## Шаги

Шаг сменяется только когда игрок сделал указанное действие.

1. **Хаб.** Подсветить силуэт «В приключение». Текст: «Нажми тропу справа. Так начинается забег.» Остальные силуэты на этом шаге не открывают экраны. Шестерёнку не блокировать. Клик по тропе открывает комнату урока.
2. **Шаг.** «Зажми WASD или стрелки. Отпустишь — остановишься. После шага ходит монстр.» Зачёт: клетка героя сменилась на соседнюю.
3. **Поворот.** «Shift и WASD или стрелки. Поворот ход не тратит, монстр от него не ходит.» Зачёт: направление героя сменилось, клетка нет.
4. **Удар.** «На полу клетки меча. ЛКМ в сторону скелета.» Зачёт: прошёл вызов удара, даже если меч никого не задел.
5. **Blink.** «ПКМ — выбор клетки. Подсвечены только допустимые. ЛКМ по одной из них. Ещё раз ПКМ отменяет и заряд не снимает.» Зачёт: герой сменил клетку через Blink и заряд уменьшился. Клик мимо и отмена шаг не закрывают.
6. **Ждать.** «X — пропуск хода. Мир всё равно ходит.» Зачёт: прошёл вызов ожидания.
7. **Добить.** «Обычный укус скелета заранее не рисуется. Бьёт соседнюю клетку по стороне, не по диагонали. Добей его.» Зачёт: комната выиграна, скелет мёртв. Текст на плашке, без нового правила.
8. **Конец.** «Двери открываются, когда враг мёртв. Tab — карта этажа. Сейчас комната одна.» Кнопка «В хаб». Она ставит ключ и открывает обычное меню. Со следующего «В приключение» идёт обычный `createRun`, не урок.

R в этот урок не входит: надет меч. Одной строкой в шаге 8: «R перезаряжает пистолет, винтовку и дробовик. Меч — нет.»

## После урока

Обычный хаб. «В приключение» собирает этаж как сейчас: стартовая комната пустая, дальше бои, надетое оружие и экипировка из инвентаря. Урок этот этаж не подменяет и золото урока в хаб не несёт: забег урока заканчивается на кнопке «В хаб» без начисления.

## Куда класть код

Модуль `room`, не новый пакет. Хаб решает, урок это или этаж. Комната урока — тот же `RoomController` с флагом шага, не вторая симуляция. Бой не копировать: шаги только разрешают уже существующие `step`, `face`, `attack`, `blink`, `wait`.
